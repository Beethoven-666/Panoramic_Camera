## GPU 使用证据

已强制启用 `G305_CUDA=required`。CUDA 设备为 NVIDIA GeForce RTX 5060 Laptop GPU；没有发生 CPU 回退。

| GPU 操作 | 次数 | 实测时间 |
| --- | ---: | ---: |
| CuPy 标定 inverse remap | 420 | 1.190 秒墙钟时间，包含主机/设备传输和公开 NumPy 边界同步 |
| Open3D Tensor CUDA RGB-D 边审计 | 59 | 计入 2.594 秒边审计阶段；本次 Open3D API 未提供逐边 CUDA event |
| D2 RAFT-small 前向推理 | 1 | 0.599 秒 CUDA event 时间；0.603 秒墙钟时间 |
| D2 RAFT-small 后向推理 | 1 | 0.044 秒 CUDA event 时间；0.047 秒墙钟时间 |
| D3 RAFT-small 真实源帧跟踪 | 59 | 2.977 秒 CUDA event 时间；3.143 秒墙钟时间 |

CUDA remap 路径主机到设备传输了 1,906,583,128 字节，设备到主机传输了 519,371,752 字节。加速审计记录为：420 次 CuPy 调用、59 次 Open3D CUDA 调用、0 次 CPU remap 调用。

## 结果状态

渲染器写入了 1,346 个仅归属于单一真实源的 D3 对象像素。结构等级与实现等级均为 A；由于 D3 Gate 3 的对象完整性尚未通过，视觉等级与总体等级仍为 C。没有运行 D4/D5 操作。
